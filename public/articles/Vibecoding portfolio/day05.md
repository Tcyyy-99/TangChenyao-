# DAY05 - 响应式优化

**日期：** 2026-06-27  
**核心目标：** 适配移动端布局，调整面包屑导航

---

## 响应式策略

### 断点设计
- **Mobile：** < 768px
- **Tablet：** 768px - 1024px
- **Desktop：** > 1024px

---

## 完成内容

### 1. 移动端侧边栏折叠
- 桌面端：固定左侧160px宽
- 移动端：隐藏，改为顶部面包屑导航

### 2. 面包屑导航
```
主页 / 作品集 / 交互设计 / 项目名称
```
- 可点击返回上级
- 当前页不可点击
- 斜杠分隔

### 3. 网格响应式调整
- 作品：3列 → 2列 → 1列
- 文章卡片：横向布局 → 纵向堆叠
- 图片宽度自适应

### 4. 字体缩放
```css
h1 { @apply text-4xl md:text-5xl lg:text-6xl; }
p  { @apply text-base md:text-lg; }
```

### 5. 触摸优化
- 增大按钮点击区域（44px最小）
- 移除hover效果，改用active态
- 滑动手势支持
