## 📝 Step 1️⃣ · 告诉AI你想要什么

打开工具，直接用中文说：

> "帮我做一个个人作品集网站，黑色背景，顶部有导航，下面展示我的作品，先用卡片占位"

**AI会搭好网站骨架** ✍🏻

### 我的实践经验：
- 用CodeMaker搭建Vibe Portfolio
- 采用React + TypeScript + Tailwind CSS
- 主页用圆形分支导航（思维导图风格）
- 黑白极简设计，突出内容本身

---

## 👀 Step 2️⃣ · 看骨架效果，反复调整

哪里不对就直接说，不满意就截图发给AI，反复调整到满意为止

**调整要点：**
- 布局合理吗？（三栏？单栏？）
- 导航清晰吗？（顶部？侧边？）
- 风格对吗？（极简？华丽？）

---

## 🖼 Step 3️⃣-1 · 放置作品图片

骨架确定后把作品图片放进去，跟AI说：

> "把某某文件夹里的图片放到网站的某个位置"

可以截图发给AI，它能识别具体位置

**我的做法：**
```
public/images/
  ├── projects/     # 作品封面
  ├── articles/     # 文章封面
  └── about/        # 关于页图片
```

---

## 📸 Step 3️⃣-2 · 填充内容

图片都放置好后，你的网站就有内容了：
- 全屏封面
- 作品板块封面
- 文章缩略图

**修改具体细节就直接跟AI自然语言描述就行**

示例对话：
- "作品卡片圆角改大一点"
- "标题字号太小了，加粗"
- "鼠标悬停时放大图片"

---

## 📀 Step 3️⃣-3 · 添加动态效果

静态内容放好后就可以给板块加动态效果

**可以让AI给你建议：**
- 淡入动画
- 悬停缩放
- 滚动视差
- 页面切换过渡

**我用的动效：**
- Framer Motion实现分支线绘制动画
- CSS transition做悬停效果
- View Transition API做页面切换

---

## ☁️ Step 4️⃣ · 上传到GitHub

网站基本搭好后就可以传到GitHub

```bash
git init
git add .
git commit -m "Initial commit"
git push
```

**相当于把文件存进网盘**，以后修改有记录 📝

---

## 🚀 Step 5️⃣ · Vercel部署

去Vercel点一下部署：

1. 登录Vercel
2. Import Project
3. 选择GitHub仓库
4. 点Deploy
5. 等2分钟

**你的网站上线了** 🎉 全世界都能访问的那种 💥

我的部署配置：
- Framework Preset: Vite
- Build Command: `npm run build`
- Output Directory: `dist`

## 🔄 以后要更新怎么办？

GitHub和Vercel都有自动更新的能力

修改完后只要跟AI工具说一句：

> "帮我推上线"

就行~ 它会自动：
1. `git add .`

3. `git push`

## 💡 使用CodeMaker的开发心得

### 与AI协作的技巧

1. **先搭骨架，再填内容**：别一开始就追求完美
2. **截图+文字描述**：让AI精确理解你的需求
3. **一次改一个点**：别一口气提10个要求
4. **保持耐心**：AI不是万能的，多试几次

### 容易踩的坑

❌ **图片太大**：压缩到200KB以下  
❌ **路径写错**：注意大小写，用相对路径  
❌ **没测移动端**：至少用Chrome模拟器看一眼  
❌ **忘记提交代码**：改完记得push

### 值得投入的优化

✅ **懒加载**：图片加`loading="lazy"`  
✅ **暗黑模式**：现代网站标配  
✅ **响应式**：手机端流量占70%+  
✅ **SEO优化**：title/description/meta标签
