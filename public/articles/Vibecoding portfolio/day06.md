# DAY06 - 文章封面功能

**日期：** 2026-06-27  
**核心目标：** 实现文章封面图显示，卡片式布局

---

## 设计思路

文章列表从纯文字改为视觉化卡片，每篇文章配独立封面图。

---

## 完成内容

### 1. 封面图管理方案
```
public/images/articles/
  ├── simulation-management-ux/
  │   └── cover.png
  ├── zelda-botw-ux/
  │   └── cover.png
  └── ...
```
每篇文章一个文件夹，封面统一命名`cover.png`

### 2. 数据结构扩展
```typescript
interface ArticleItem {
  // ... 其他字段
  coverImage?: string; // 新增
}
```

### 3. 卡片布局设计
```
┌────────────────────────────────────┐
│ ┌──────┐  标题                      │
│ │ 封面 │  日期                      │
│ └──────┘                           │
└────────────────────────────────────┘
```
- 左侧：128×96px封面图
- 右侧：标题+日期
- 悬停放大

### 4. 降级方案
无封面时显示渐变色块 + 分类名称竖排

### 5. 批量创建文件夹
创建13个文章文件夹，准备封面图资源

---

## 视觉优化

- **圆角：** rounded-xl (12px)
- **边框：** hover时黑色高亮
- **动画：** group-hover缩放
