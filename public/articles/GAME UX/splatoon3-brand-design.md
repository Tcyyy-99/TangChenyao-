# 斯普拉遁3品牌IP塑造分析

> 街头潮流风格 + 涂地战争玩法，全球销量2300万+

---

## 品牌视觉体系

### 1. 品牌符号

随游戏迭代在数字上融合品牌元素进行变形：鱿鱼斑纹、眼睛、三角头特征

### 2. 品牌色

- 每一代修改一次主色
- 辅以黑白灰调节整体视觉感受

### 3. 品牌字体

与鱿鱼形象特征呼应：厚实、宽松、运动感

### 4. 辅助元素

采用与游戏玩法、形象强相关的元素：液体、斑点纹理、箭头

### 5. 动态视觉

通过流动性、弹性动效贴合鱿鱼特征

---

## 设计亮点

### 整体视觉统一性

```
大面积高饱和度高鲜明度颜色
灰黑色作为辅助
契合涂地玩法与街头涂鸦主题
传递活泼、欢乐调性
```

### IP塑造强化

```
游戏世界中衍生出多种玩法：
- 时尚服装
- 游戏广场
- 虚拟偶像
- 乌贼演唱会
- 祭典、问答比赛

与现实生活强链接，成为社交话题
```

---

## 核心启示

| 方向 | 启示 |
|------|------|
| 视觉统一 | 高饱和度色彩 + 玩法暗藏 |
| 品牌元素 | 辅助元素暗藏玩法 |
| IP延展 | 生活化融合，社交传播 |
