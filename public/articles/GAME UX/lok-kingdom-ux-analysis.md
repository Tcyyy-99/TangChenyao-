# 捉宠品类游戏UX设计方法论

> 以《洛克王国：世界》为例，解析国民IP的体验设计密码

---

## 核心命题

> 捉宠品类的核心体验不在于"捉"，而在于**收集与成长的情感连接**。

---

## 一、市场背景与IP价值

### 1.1 赛道机会

```
时间窗口：2020-2026年
市场空白：国内无大世界捉宠产品
竞品状态：米哈游/蛮啾等新品尚未公测

先发优势：首款大世界捉宠产品
          全平台预约6000万+
          注册用户3000万+
          畅销榜前十
```

### 1.2 IP情感基础

| 维度 | 价值 |
|------|------|
| 早期积累 | 2010年页游时代第一批成体系捉宠游戏 |
| 用户情感 | 90后/00后群体情感浓度极高 |
| 门槛 | 对小学生上手门槛极低 |

## 二、玩法循环设计

### 2.1 三层嵌套结构

```
┌─────────────────────────────────────┐
│         开放世界捉宠探索            │  ← 承接探索&收集
├─────────────────────────────────────┤
│         进化版回合制战斗            │  ← 核心交互
├─────────────────────────────────────┤
│          宠物7维养成体系            │  ← 成长驱动
└─────────────────────────────────────┘
```

### 2.2 大世界探索设计

#### 内容容量

| 指标 | 数据 |
|------|------|
| 地图面积 | 4.55平方公里 |
| 区域数量 | 35个差异化区域 |
| 副本数量 | 32个 |
| 宝箱数量 | 1300+ |
| 采集点 | 490+ |

#### 收集驱动设计

| 维度 | 数据 |
|------|------|
| 可捕捉精灵 | 437种（首赛季） |
| 属性类型 | 18种 |
| 特殊变种 | 炫彩/异色/地区形态/噩梦形态 |

**设计目的**：实际收集目标远超基础数字

### 2.3 图鉴激励机制

#### 登门槛效应应用

```
节点：每10只精灵
奖励：棱镜球/国王球/精灵果实

心理机制：
69只 → "差1只就拿到了" → 动力唤醒
                ↓
将大目标拆解为多个短期目标
                ↓
对抗大世界探索中的目标失焦
```

## 三、战斗系统创新

### 3.1 基础框架

```
结构：6宠1V1车轮战
规则：当前精灵HP归零则强制换宠
核心：资源管理 + 换宠时机判断
```

### 3.2 传统问题 vs 创新解法

| 维度 | 《宝可梦》传统设计 | 《洛克王国：世界》创新 |
|------|--------------------|------------------------|
| 资源系统 | PP值（每个技能独立） | 能量点（10点共享） |
| 问题 | 站场消耗拖节奏 | 进攻机会成本直接 |
| 学习成本 | 高（隐性规则多） | 低（可视化+简单） |

### 3.3 能量点设计优势

```
共享能量点 → 磨时间无意义
        ↓
双方都有动力进攻
        ↓
配合速度/属性克制可视化
        ↓
新手也能快速建立掌控感
```

## 四、养成体系设计

### 4.1 七维养成

| 维度 | 随机性 | 可修正 |
|------|--------|--------|
| 等级 | 固定 | - |
| 性格 | 高随机 | 可修正 |
| 个体值 | 高随机 | 可修正 |
| 资质 | 随机 | 可修正 |
| 技能 | 随机 | - |
| 特长词条 | 随机 | - |
| 炫彩 | 随机 | 付费 |

### 4.2 从"刷极品"到"刷功能"

```
传统痛点：刷完美精灵 ≈ 1/600概率
                ↓
《洛克王国》解法：
├── 数值可修正
├── 动机迁移：刷极品 → 刷技能书/特长词条
└── 词条对应不同实用场景
                ↓
关系转变：
"刷同一只精灵的极品版本"
    ↓
"广撒网收集有功能价值的精灵"
```

## 五、社交生态设计

### 5.1 社交定位策略

```
完全单机 ←─────→ MMO多人同屏
                │
                ↓
        镜像形式呈现
        野外互不干扰
        主城/传送点集中
        需主动牵手邀请
```

### 5.2 牵手系统设计

| 功能 | 效果 |
|------|------|
| 经验共享 | 捉宠/探索经验全额共享 |
| 资源回复 | 好友可为房主回复耐力 |
| 共同战斗 | 牵手参与PVE战斗 |
| 捕捉加成 | 污染精灵概率↑ + 捕捉收益翻倍 |
| 宠物转赠 | 战斗中捕捉的宠物可转赠 |

**核心价值**：社交互动 = 实质性效率提升

### 5.3 利他性设计

```
社交驱动核心：
├── 初始宠物/战令宠补全 → 需好友世界捕捉
├── 高收集度好友世界 → 提前捕捉目标宠物
└── 好友列表质量 → 养成加速收益
```

### 5.4 对比分析

| 维度 | 宝可梦GO | 宝可梦剑盾 | 洛克王国：世界 |
|------|----------|------------|----------------|
| 互动形式 | 附近 | 奇迹交换 | 牵手+世界访问 |
| 利益驱动 | 低 | 中 | **高** |
| 功能性 | 弱 | 中 | **强** |
| 情感属性 | 强 | 强 | 中 |

## 六、商业化设计

### 6.1 当前模式

```
核心：外观付费（合规路线）
辅以：少量功能性道具
原则：不卖数值
```

### 6.2 商业化挑战

#### 主角外观

| 问题 | 分析 |
|------|------|
| 展示场景有限 | 主角不参与战斗 |
| 高频画面 | 宠物占据 |
| 付费动机 | 非核心社交用户吸引力弱 |

#### 炫彩系统

| 档位 | 价格 | 内容 |
|------|------|------|
| 基础 | 160元 | 随机炫彩 |
| 进阶 | 1600元 | 自选非黑白 |
| 顶配 | 约16000元 | 锁定黑白炫彩 |

**问题**：价格梯度陡峭，中低付费层转化路径模糊

## 七、核心隐患分析

### 7.1 内容供给失衡

| 问题 | 现状 |
|------|------|
| 长线高难PVE | **缺位** |
| 叙事吸引力 | 子供向，成年玩家吸引力有限 |
| 终局目标 | **明显真空** |

### 7.2 消耗产出失衡

```
重度用户全收集周期：约1周
赛季更新：11只精灵 + 18种异色变种
                ↓
补充节奏 << 消耗速度
```

### 7.3 留存逻辑挑战

| 路径 | 现状 |
|------|------|
| 图鉴收集 | 容量上限可预期 |
| PVP竞技 | 高门槛用户覆盖有限 |
| 高难PVE | **暂时缺位** |
| 社交驱动 | 主要依赖，但需持续验证 |

---

## 八、设计启示

### 8.1 成功信号

| 信号 | 启示 |
|------|------|
| 情怀吸量有效 | 但时间窗口有限 |
| 社交利益化 | 值得深挖的核心方向 |
| 外观付费保守 | 规避口碑风险，牺牲部分变现 |

### 8.2 风险警示

```
1. 情怀消耗速度 > 内容补充速度
2. 过度功能化 → 情感社交空间压缩
3. 商业化路径无成熟案例
4. 竞品入场后格局将快速变化
```

### 8.3 设计建议

| 方向 | 建议 |
|------|------|
| 内容供给 | 加快赛季更新节奏，补齐高难PVE |
| 社交平衡 | 功能化与情感化需持续校准 |
| 商业化 | 中低付费层转化路径需优化 |

---

## 总结

| 设计维度 | 核心策略 | 创新价值 |
|----------|----------|----------|
| **玩法循环** | 三层嵌套 | 能量点系统创新 |
| **收集驱动** | 图鉴里程碑 | 登门槛效应应用 |
| **养成体系** | 数值可修正 | 动机从刷极品到刷功能 |
| **社交生态** | 牵手+利益绑定 | 社交功能化 |
| **商业化** | 外观付费 | 保守合规 |

**最终目标**：让玩家感受"收集有价值、成长有反馈、社交有效益"的捉宠体验。
