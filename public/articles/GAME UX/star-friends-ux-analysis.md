# 星绘友晴天UX/UI综合体验拆解报告

---

## 一、产品定位与核心体验框架

### 产品形态
网易推出的"立方体星球建造 + 派对社交"休闲游戏

### 核心循环
```
种田建造 ➔ 获取资源 ➔ 参与派对120+小游戏 ➔ 获得奖励 ➔ 反哺星球建设
```

### 体验差异化
- 独特的"六面可建的魔方星球"设定
- 恐龙主角设定，形成独树一帜的辨识度

---

## 二、UX/UI亮点设计

### 高自由度的视觉定制

| 功能 | 设计要点 |
|------|----------|
| 角色创建 | 支持性别、发型、背鳍、花纹等细节调整的"丑萌"捏脸系统 |
| 建造系统 | 星球与家园支持瀑布、梯田等创意造景 |
| 正反馈 | 成就感给得非常及时 |

### 沉浸式与自动化交互

| 设计 | 说明 |
|------|------|
| 智能UI切换 | 系统会根据当前环境自动切出工具（如靠近水自动出鱼竿） |
| 防遮挡设计 | 被建筑物遮挡时智能生成"辅助小窗" |
| 减负设计 | 洒水机、播种机等自动化设备，符合"星际科技种田"设定 |

### 驱动探索的激励机制

- 见闻集卡系统：用打卡解锁形式满足收集欲
- 万物扫描仪：探索驱动的激励机制
- 新手引导：克制且不强制弹窗打断，将选择权交还玩家

## 三、交互痛点与优化建议

### 1. 操作手感、视角与角色动作

| 痛点 | 优化建议 |
|------|----------|
| 移动轮盘尺寸偏小，易误触 | 开放自定义HUD界面 |
| 默认镜头距离过近，易3D眩晕 | 提供远近多档视角预设并记忆参数 |
| 不记忆玩家自定义视角 | 参数自动保存 |
| 物体交互判定范围严苛 | 适度扩大交互判定范围 |
| 角色奔跑动作前摇过长 | 缩短奔跑动作前摇，优化移动手感 |

### 2. 地图与场景动画

| 痛点 | 优化建议 |
|------|----------|
| 星球地图不支持目标人物追踪 | 新增玩家、好友点位追踪功能 |
| 跨星球跳转动画无法跳过 | 增加动画跳过按钮 |

### 3. 菜单与交互层级

| 痛点 | 优化建议 |
|------|----------|
| 背包、合成、交易整合在平板UI，信息臃肿 | 拆分平板复合功能，分设独立快捷面板 |
| 快捷栏可容纳道具数量不足 | 扩充多排快捷栏 |
| 商店需通过冗长NPC对话解锁 | 去除对话前置门槛，直接开放商店快捷入口 |

### 4. 反馈机制与画面渲染

| 痛点 | 优化建议 |
|------|----------|
| 农作物成熟无全局倒计时 | 大世界增加作物成熟进度条/倒计时常驻提示 |
| 采花、钓鱼等操作动画时长偏长 | 提供动画跳过、批量采集操作 |
| 草地纹理粗糙，与建筑落差大 | 优化草地材质纹理，统一场景渲染精度 |

### 5. NPC人设与交互

| 痛点 | 优化建议 |
|------|----------|
| NPC人设同质化严重 | 参考《动物森友会》NPC设计思路 |
| 命名带强性别标签（xx哥） | 调整NPC命名体系，弱化性别标签 |
| 对话模板固定，互动单调 | 丰富NPC专属剧情、随机互动对话 |

### 6. 引导缺失与外设适配

| 痛点 | 优化建议 |
|------|----------|
| 下矿、商城等核心系统缺少引导 | 新增可随时打开的《星际生存手册》 |
| PC端手柄按键无响应 | 全面优化PC端手柄键位映射 |
| 交互浮标辨识度低 | 放大高亮功能浮标 |

### 7. 社交匹配与商业化

| 痛点 | 优化建议 |
|------|----------|
| 派对匹配排队时间久 | 优化匹配算法，降低等待时长 |
| 小游戏失败需氪金复活 | 增设每日免费复活次数，或支持游戏基础资源兑换 |

## 四、整体评价与玩家画像

### 产品优势
- 魔方星球世界观创意独特
- 捏脸、建造自由度高
- 自动化减负交互
- 轻量化新手引导

### 现存短板
- 操作手感、镜头逻辑打磨不足
- 界面层级繁琐
- 动画等待成本高
- NPC人设单一
- 画面渲染质感参差不齐
- 商业化对轻度玩家不够友好

### 适用人群

| 适合 | 不适合 |
|------|--------|
| 偏爱慢节奏建造 | 追求高效操作 |
| 轻度线上社交的休闲玩家 | 反感冗长动画 |
| - | 对竞技付费敏感 |

---

## 五、核心优化建议汇总

| 痛点 | 解决方案 |
|------|----------|
| 地图不支持人物追踪 | 地图增加人物、好友点位追踪标记 |
| 跨星球跳转动画无法跳过 | 新增动画跳过按钮 |
| NPC人设刻板 | 调整NPC命名体系，弱化性别标签，丰富个性化对话 |
| 钓鱼操作繁琐 | 支持鼠标左键直接垂钓，或F键自动切换水域工具 |
| UI遮挡鱼群 | 调整钓鱼UI渲染层级，转动视角时自动隐藏 |
| 奔跑动作前摇过长 | 缩短奔跑动作前摇 |
| 草地纹理粗糙 | 优化草地材质纹理，统一场景渲染精度 |
