# 动物森友会社交分级设计分析

> 细化社交距离，让每个玩家都能找到舒适的社交状态

---

## 核心问题

```
社交圈扩大后：私人空间变成公共场所
解决方案：细化社交分级，保持舒适度
```

---

## 好友等级设计

| 等级 | 邀请方式 | 权限 |
|------|----------|------|
| 陌生人 | 密码邀请 | 仅采集可再生资源 |
| 好友 | 搜索自行上岛 | 可自由进出 |
| 最佳好友 | 申请+邀请 | 使用所有工具 |

### 设计细节

- 开门时区分"好友"与"最佳好友"
- 上岛时只有统一的"好友"概念
- 不在类别列表里不会显示对方岛

---

## 社交距离保障

### 信息控制

```
最佳好友申请：
- 层级深，轻提示
- 不阻断体验但易被忽视

非最佳好友：
- 不可私信
- 社交锁定在"上岛"环节
```

## 0社交玩法

### 丰富内容支撑

| 内容 | 说明 |
|------|------|
| 素材库 | 庞大随机系统 |
| 物种 | 南北半球季节变化 |
| 个性化 | 家具/装扮/地板/壁纸海量 |

---

## 总结

| 手段 | 作用 |
|------|------|
| 区分好友等级 | 流程开始前建立清晰社交目标 |
| 最佳好友申请 | 社交过程中对信息有效控制 |
| 0社交玩法 | 提供足够完整的玩法内容支撑 |
